# Greenfield Coffee Shop

A greenfield demo application for a modern coffee shop, built with Node.js.

## About

This project is a from-scratch ("greenfield") implementation of a coffee shop web application. It serves as a demo/learning project covering common patterns such as menu browsing, order placement, and basic inventory management.
